# creatio.design (deployed site)

This repository serves creatio.design through GitHub Pages (branch `main`, `CNAME`).
It holds the built static site only. The source, the design rules (`AGENTS.md`) and the approved copy (`content/`) live in [hiCreatio/creatiowebsite](https://github.com/hiCreatio/creatiowebsite).

To update: copy `index.html`, `favicon.svg`, `work/`, `assets/` and `design-system/` from that repository and push here. Keep `CNAME` and `.nojekyll`.
The previous site (before 2026-10-08) remains in this repository's history.
